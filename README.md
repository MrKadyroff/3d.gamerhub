# 3D.GAMERHUB — лендинг 3D-печати (Алматы)

Одностраничник с 3D-превью моделей, «нарезкой» слоями и калькулятором стоимости.
Заявка вместе с файлом падает тебе в Telegram, файл сохраняется на сервере.

## Запуск

```bash
npm install          # ставит зависимости и копирует three.js в public/vendor
cp .env.example .env # вписать токен бота и chat_id
npm start            # http://localhost:3000
```

Без `.env` сайт работает, просто заявки не улетают в Telegram — они всё равно
пишутся в `uploads/orders.jsonl`, а модели ложатся в `uploads/`.

## Telegram

Токен уже прописан в `.env` (бот `@mrk_notify_bot`). Осталось определить, в какой чат слать:

```bash
npm run tg:chat     # запусти и напиши боту /start — chat_id впишется в .env сам
npm start           # перезапусти сервер
```

На каждую заявку приходит:

1. **Картинка модели** (1280×960) — как она выглядит и в каких цветах, с карточкой заказа в подписи;
2. **Кнопки** «Написать в Telegram» / «WhatsApp» — если клиент оставил @ник или телефон;
3. **Сам файл модели** (STL/OBJ/3MF) — можно сразу кидать в слайсер.

Всё дублируется в `uploads/orders.jsonl`, файлы и превью лежат в `uploads/`.
Если Telegram недоступен, заявка всё равно сохраняется — уведомление просто не уйдёт.

## Что где править

| Что | Файл |
|---|---|
| **Все цены и коэффициенты** | `public/js/pricing.js` |
| Telegram / WhatsApp / телефон | `CONTACTS` в начале `public/js/app.js` |
| Портфолио (подписи) | `WORKS` в `public/js/app.js` |
| Портфолио (картинки) | `public/img/works/` — заменить на свои фото |
| Вопросы-ответы | `FAQ` в `public/js/app.js` |
| Тексты, заголовки, SEO | `public/index.html` |
| Цвета темы | переменные `:root` в `public/styles.css` |

Иллюстрации принтера и AMS (`img/p1s.svg`, `img/ams.svg`) — нарисованные векторные
стилизации, не фото Bambu Lab. Если нужны настоящие фото — положи свои снимки
принтера, будет живее и без вопросов по правам.

## Как считается цена

```
материал = объём_оболочки + объём_внутри × заполнение   → граммы × ₸/г
время    = объём_пластика / производительность × коэф. слоя × коэф. AMS + прогрев
итого    = (материал + время×₸/час + доплата за цвета + подготовка)
           × срочность, но не меньше минимального заказа
           × количество × скидка за тираж
```

Фронт считает для показа, сервер **пересчитывает заново** при приёме заявки —
в Telegram приходит серверная цифра, подменить её из браузера нельзя.

## Конструктор надписей

Секция «Конструктор» (`#maker`) генерирует настоящую 3D-модель из введённого текста —
брелок с кольцом, табличку или объёмные буквы. Геометрия строится в браузере
(`public/js/maker.js`), по ней считаются объём, вес и цена, а при заказе она
экспортируется в бинарный STL и уходит тебе в Telegram как обычный файл.
В карточке заявки такие заказы помечены 🎮 и текстом надписи.

Шрифт — `droid_sans_bold` из поставки three.js: латиница и кириллица есть,
казахские Қ, Ә, Ғ, Ң, Ө, Ұ, Ү, Һ — нет. Такие символы отсеиваются, и пользователь
видит предупреждение. Если нужны — надо подложить свой шрифт в формате
typeface.json в `public/vendor/fonts/` и поменять `FONT_URL` в `maker.js`.

Параметры печати для конструктора (PLA, слой 0.2, заполнение 40%) заданы
константой `MK_PARAMS` в `public/js/app.js`.

## Фото принтера

В `public/img/` лежат **нарисованные** векторные иллюстрации (`p1s.svg`, `p1s-large.svg`, `ams.svg`),
а не фотографии Bambu Lab. Чтобы поставить настоящее фото — просто положи рядом файл
с тем же именем и расширением `.jpg`:

```
public/img/p1s.jpg         # в первый экран
public/img/p1s-large.jpg   # в блок «Оборудование»
public/img/ams.jpg         # модуль AMS
```

Разметка подхватит его автоматически, а если файла нет — покажет рисунок. Ничего править не нужно.
Лучше всего снять собственный принтер: живое фото с реальными деталями на столе продаёт
сильно лучше стокового рендера, и вопросов по правам не возникает.

## Цены (рынок Алматы, август 2026)

Ориентиры, по которым откалиброван `pricing.js`:

- катушка PLA ~8 500 ₸/кг, PETG ~10 000 ₸/кг — себестоимость материала;
- услуги печати в городе: 30–45 ₸/г у бюджетных студий, 60–90 ₸/г у premium;
- минимальный заказ на рынке ~1 500 ₸.

Итоговая цена в калькуляторе выходит 41–57 ₸/г на реальных деталях и 1 500 ₸ на мелочи —
чуть выше бюджетного сегмента, что оправдано P1S + AMS.

## Галерея «Что печатают»

Карусель на 20 карточек, по 4–5 в ряд (адаптируется: 5 → 4 → 3 → 2 → 1 по ширине экрана),
с автопрокруткой каждые 5 секунд, стрелками, точками и свайпом. Клик по карточке
подставляет материал и высоту слоя в калькулятор и прокручивает к нему.

Картинки собираются скриптом:

```bash
python3 scripts/gallery.py      # перекачает и пересоберёт manifest.json
```

Не запускай две копии одновременно: они пишут в один `manifest.json` и он разъедется
с файлами. Проверить целостность — число записей в манифесте должно совпадать
с числом `.jpg` в каталоге.

Скрипт берёт изображения через [Openverse](https://openverse.org) — только те лицензии,
что разрешают коммерческое использование (CC BY, CC BY-SA, CC0). Подпись к каждой карточке
выводится из названия самого изображения, чтобы не подписать шестерню «маской».
Авторы и лицензии складываются в `manifest.json` и печатаются строкой под галереей —
**этого требуют CC BY и CC BY-SA, удалять эту строку нельзя.**

**Это не портфолио.** Секция честно называется «Что печатают» и подписана как примеры
типовых изделий. Выдавать чужие фотографии за свои работы нельзя — клиент придёт с такой
картинкой и попросит повторить. Когда наберутся свои фото:

1. положи их в `public/img/gallery/` как `01.jpg … 20.jpg`;
2. поправь `manifest.json` (`label`, `hint`, `preset`; поля `author`/`license`/`source` убери);
3. переименуй секцию в `index.html` обратно в «Наши работы» и удали строку с авторством.

## Личный кабинет клиента

Заказы клиента живут в **постоянной панели у правого края** — ярлык «Мои заказы» виден
на любом экране страницы, со счётчиком заявок. Клик разворачивает панель со списком:
миниатюра модели, номер, дата, цена, статус. Ярлык пульсирует, пока заказ в работе.
Панель открывается сама сразу после оформления заявки.

История лежит в `localStorage` браузера клиента (`gamerhub.orders`, последние 20 заказов
с миниатюрами) — без регистрации, паролей и базы данных. Очистит браузер — история пропадёт,
но сами заказы останутся у тебя в `uploads/orders.jsonl`.

На телефоне панель превращается в шторку снизу, ярлык уезжает к нижнему краю.

**Статусы.** В карточке заявки в Telegram есть кнопки `✅ Принял` / `🖨 Печатаю` / `📦 Готов`.
Нажатие меняет статус, и клиент видит его у себя в кабинете — при открытии страницы
и при возврате на вкладку. Статусы хранятся в `uploads/status.json`.

Сервер держит длинный опрос `getUpdates`, чтобы ловить нажатия. Из-за этого
**нельзя одновременно запускать `npm run tg:chat` и сервер** — Telegram отдаёт апдейты
только одному потребителю. Останови сервер, узнай chat_id, запусти обратно.

## Цвета пластика

Список в `PRICING.colors` (`public/js/pricing.js`) — что там перечислено, то и предлагается клиенту.
Убирай цвета, которых нет в наличии, добавляй свои: `{ id, label, hex }`, флаг `silk: true` даёт
глянцевый шёлковый вид в превью.

В режиме **AMS** палитра становится множественным выбором: клиент отмечает 2–8 цветов,
превью раскладывает их полосами по высоте печати — ровно так, как AMS меняет филамент по слоям.
Число выбранных цветов идёт в расчёт (`perExtraColor`) и в заявку.

## Форма заявки

Обязателен **только телефон** — имя и комментарий можно не заполнять, заявка всё равно уйдёт.
Пустое имя записывается как «Без имени». Телефон проверяется и на клиенте, и на сервере:
минимум 10 цифр либо `@ник` длиннее 4 символов.

Отдельной галочки согласия нет — вместо неё строка мелким шрифтом под кнопкой
(«Отправляя заявку, ты соглашаешься…»). Это убирает лишний клик, но если для Казахстана
нужна явная отметка о согласии на обработку персональных данных — верни чекбокс
с `required` в `public/index.html`.

## Запуск в бой

```bash
npm install
cp .env.example .env      # вписать TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID
npm start
```

Проверка живости — `GET /healthz`, отвечает `{ok, telegram, uptime}`.
Годится для мониторинга и healthcheck балансировщика.

### Что уже сделано для продакшена

- **Ограничение частоты**: 6 заявок с одного IP за 15 минут, 60 запросов статуса в минуту.
  Без этого один скрипт завалил бы Telegram спамом и забил диск 60-мегабайтными файлами.
- **Заголовки безопасности**: `nosniff`, `SAMEORIGIN`, `Referrer-Policy`, `Permissions-Policy`;
  `X-Powered-By` убран.
- **`trust proxy`** включён — за nginx в лимитах виден реальный IP клиента, а не адрес прокси.
- Загрузки лежат вне `public/`, наружу не отдаются; обход каталогов проверен.
- Цена пересчитывается на сервере — подменить её из браузера нельзя.
- SEO: og-теги, canonical, `robots.txt`, `sitemap.xml`, разметка LocalBusiness для поиска.
- **Кэширование**: HTML, JS и CSS отдаются с `no-cache` — браузер перепроверяет их
  на каждой загрузке (дёшево, обычно 304). Иначе после обновления сайта у людей
  остаётся старый JS, он спотыкается о новую разметку, и страница молча ломается.
  Картинки и вендорные библиотеки кэшируются на неделю.

### Что нужно сделать при деплое

1. **Домен и HTTPS.** В коде указан `3dgamerhub.kz` (canonical, og:image, sitemap) —
   если домен другой, поправь в `public/index.html`, `robots.txt`, `sitemap.xml`.
   Сертификат и HTTPS вешаются на nginx, сам Node их не делает.
2. **Автозапуск.** `pm2 start server.js --name gamerhub` или unit для systemd:
   без этого сервер умрёт вместе с ssh-сессией.
3. **Nginx** — проксировать на `127.0.0.1:3000`, поставить `client_max_body_size 70m`
   (иначе большие модели не дойдут) и передавать `X-Forwarded-For`.
4. **Отозвать токен бота.** Текущий токен пересылался в переписке — для боевого
   запуска выпусти новый у @BotFather.
5. **Бэкап `uploads/`** — там и заявки (`orders.jsonl`), и сами модели клиентов.
   Каталог растёт без ограничений, за местом стоит следить.
